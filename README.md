# 🐍 Aprendendo Python

Repositório criado para registrar minha jornada de aprendizado em **Python**, começando do zero e avançando gradualmente para conceitos mais práticos e desenvolvimento de projetos.

O objetivo é utilizar este repositório como um espaço para guardar exercícios, ideias, anotações e projetos desenvolvidos durante meus estudos de programação.

---

## 🎯 Objetivo

Aprender Python desde os fundamentos e construir uma base sólida para posteriormente desenvolver projetos mais completos.

Durante os estudos, estou praticando conceitos como:

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Listas e outras estruturas de dados
- Funções
- Tratamento de erros
- Organização de projetos
- Bibliotecas e módulos
- Programação orientada a objetos
- Desenvolvimento de projetos práticos
